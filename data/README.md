# Baseline files bundled with this release

Each dataset directory contains three files: `<dataset>_nodes.csv`, `<dataset>_features.csv`, and `<dataset>_multi_relational_zero_shot_edges.csv`.

These are not sufficient to run downstream without the generated Step7 graph/date arrays or the upstream Student/OOF prediction CSVs. Those generated assets are intentionally excluded from Git.

Check licenses and data provider redistribution conditions before publishing this repository.
